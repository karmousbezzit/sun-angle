# sun-altitude
A simple SwiftBar script to display Sun altitude.

## Instructions
1. Install SwiftBar: https://github.com/swiftbar/SwiftBar
2. Download the `sun-altitude.1m.py` script
3. Customize the values of `LOCATION_NAME`, `LATITUDE` and `LONGITUDE`
(there is a code comment explaining why it's not automated)
4. Place the script in SwiftBar's plugin folder
